# Keycloak Theme

This repository supplies the `neurwerk` login and email theme inside a Keycloak container image. Keycloak owns authentication flows and email delivery; Base owns platform deployment and realm configuration.

- [Architecture](architecture/README.md): inheritance, templates, assets, and customization boundaries.
- [Development](development/README.md): image build and disposable local preview.
- [Operations](operations/README.md): installation, theme selection, branding, and release ownership.
