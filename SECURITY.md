# Security Policy

## Supported versions

Security fixes target the latest released version and the `main` branch. Older versions may require upgrading to receive a fix.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately through [GitHub private vulnerability reporting](https://github.com/neurwerk/k8s_stack_keycloak_theme/security/advisories/new). If private reporting is unavailable, contact `dev@neurwerk.com`.

Include the affected version, impact, and reproduction steps using synthetic data. Never include credentials, private keys, access tokens, personal data, or real client configuration. Do not test systems without the owner's permission.

Maintainers will investigate the report and coordinate remediation and disclosure with the reporter. Keep vulnerability details private until disclosure is agreed.
